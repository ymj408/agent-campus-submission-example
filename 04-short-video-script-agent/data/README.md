## 关键约束

- P01 是参考实例素材，**只有“支持字幕”一个产品事实**；没有任何效果数据。
- 脚本中若出现“效率提升 80%”等结论，规则检查必须阻断。
- 每个 `claims[].text` 必须能在同 `material_id` 的 `facts` 中找到。
- 时长目标由任务给出；平台时长范围见 `brand_rules.json`。

## 参考实例

目标 30 秒：

```text
首稿 38 秒 → 时长检查不通过
压缩稿 28 秒 → 时长检查通过
规则检查通过 → 输出分镜、P01 引用、总时长
```

无效果数据时，不能添加“效率提升 80%”等结论。
