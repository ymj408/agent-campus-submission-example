# data/ 合成资料

本目录中的素材、排期、规则和补充工单全部为合成数据，不包含真实用户、品牌或账号信息。

| 文件 | 用途 |
|---|---|
| `materials.json` | 6 个测试素材；M01 有冲突、M02 信息缺失、M04 规则风险、M05 保存失败、M06 人工复核 |
| `rules.json` | 可解释的规则库：必填字段、版权、平台、禁用表述、敏感主题、标题长度 |
| `schedule.json` | 已有确认排期；2026-11-06 18:00 douyin 被 M99 占用 |
| `source_notes.json` | 模拟制作系统补查；M02 可补回版权，但仍缺时长 |

## 语义边界

- `schedule.json` 是只读的已有排期，不是本 Agent 的发布结果。
- `publish_at` 表示素材原始/用户要求时间；任务输入中的 `requested_publish_at` 是本次硬性要求。
- 时段冲突按“平台 + 时间点”判断；草稿也占用时段，但可以幂等复用。
- 修改 `rules.json` 后，已有草稿不会自动重算；运行期保存时会重新审核。
